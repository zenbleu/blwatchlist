# BL Watchlist

## Project overview

BL Watchlist is a Vite-powered React application for organizing BL series and movies. The runnable web app lives in `app/`, uses pnpm, and stores watchlist data in the browser with IndexedDB.

## Running locally

```bash
cd app
pnpm dev
```

The development server runs on port 5000 in the Replit workflow.

## User preferences

- Keep the existing React/Vite structure and `app/` project boundary.
